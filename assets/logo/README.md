# YASAD logo

| File | Use |
|------|-----|
| `logo-black.svg`, `logo-black.png` | Black logo, for light backgrounds. |
| `logo-white.svg`, `logo-white.png` | White logo, for dark backgrounds. |
| `source/logo.afdesign` | Editable source (Affinity Designer). |

PNG files are 2048 x 2048 with a transparent background. Prefer the SVG when possible.
